DESCRIPCIÓN 
Una aplicación iOS que permite explorar, buscar y guardar libros de la API pública de Open Library. La app almacena los favoritos localmente en el dispositivo sin necesidad de login, y funciona tanto con conexión como sin ella

FLUJOS
Explorar desde Inicio
Usuario abre la app → Ve una lista de libros (puede ser un feed curado o resultados de una búsqueda por defecto: ej. "ficción clásica") → Toca un libro → Detalle con portada, título, autor, año y descripción → Opción de guardar a "Mis libros".
Buscar y Filtrar
Usuario toca pestaña Buscar → Campo de entrada + búsquedas recientes → Escribe título o autor → Toca buscar → Resultados de Open Library (lista scrolleable) → Toca un resultado → Detalle → Guardar o no.
Gestionar Guardados
Usuario toca pestaña Mis libros → Ve grid de libros guardados (con portada, título, autor) → Toca un libro → Detalle del guardado → Opción de quitar de "Mis libros" → Vuelve a la lista.
